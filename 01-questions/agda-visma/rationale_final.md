# Agda/Visma Interview Questions - Rationale Guide (Streamlined)
## Table Format - 28 Strategic Questions

---

## Section 1: Opening & Overview

| Question | Rationale |
|----------|-----------|
| **How long have you been the super user for Agda/Visma?** | Establishes Helena's credibility and experience depth. Long tenure (5+ years) = Deep institutional knowledge, system evolution understanding, recommendations carry weight. Newer (<1 year) = Fresh perspectives but limited context. High turnover = System or organizational problems. Key person dependency risk if Helena is sole expert. |
| **What's your primary role beyond managing this system?** | Reveals if HR/Payroll is strategic (dedicated) or tactical (add-on). Dedicated = Adequate resources, proper attention, optimization possible. Multiple hats = Stretched thin, underutilization likely, reactive not proactive. Signals: Is HR valued? If overwhelmed, system won't be used optimally regardless of capabilities. |
| **In your own words, what HR and payroll functions does Agda/Visma handle?** | Tests understanding and reveals utilization. Should mention: payroll, benefits, time, self-service, recruitment, performance, reporting, compliance. Limited answer = 30-40% utilization, overpaying 50%+. Comprehensive answer = Good use. Misalignment = Training gaps. |
| **How many employees' data does this system manage?** | Scale determines cost-per-employee. Benchmarks: 200-500 SEK/employee/year mid-market, 100-300 enterprise. Calculate: Annual cost ÷ employees. 50 employees might be overpaying, 500+ needs scalability. Also affects urgency: 50 = manageable backup, 500 = crisis if fails. |

## Section 2: System Value & Criticality

| Question | Rationale |
|----------|-----------|
| **What would happen if Agda/Visma was unavailable during payroll week?** | Tests TRUE criticality vs. perceived. "Payroll would stop" = Mission critical. "Could manage with Excel" = Important but not critical, possibly overinvested. "Done manual before" = Good continuity planning. No backup = Unacceptable risk. Reveals: preparedness, actual dependency, necessity vs. convenience. |
| **On a scale of 1-10, how critical is this system? Why?** | Quick comparison metric but reasoning matters more. Should be 8-9 for HR/Payroll. Rating 9-10 with clear reasoning = Credible, justified. Rating 5-6 = Question value. Vague "we use it daily" = Confusing frequency with criticality. Strong answer includes specific consequences of unavailability. |
| **Does this system handle compliance and statutory reporting adequately?** | **HIGHEST PRIORITY for Swedish payroll.** Compliance failures = legal/financial consequences. Must handle: Skatteverket, social fees, pensions, Försäkringskassan, collective agreements. "Yes, automatic" = GREEN FLAG. "Manual supplement" = YELLOW FLAG. "Not sure" = **RED ALERT, compliance risk.** Non-compliance: penalties 50,000-500,000 SEK. This alone justifies investment. |

## Section 3: Usage & Adoption

| Question | Rationale |
|----------|-----------|
| **How frequently do you access the system?** | Frequency indicates workflow integration. Daily = Core operations. Weekly = Regular but not constant. Monthly = Primarily payroll cycles, might indicate underutilization. For HR Manager of 200+ employees, daily use expected. Less frequent = Either excellent automation (good) or poor integration (concerning). |
| **Who are the primary users? (HR only, managers, all employees?)** | User scope determines if self-service value realized. HR only = Limited value, missing benefits. Managers using = Reduced HR workload. All employees = Maximum value. Paying for self-service but only HR uses = Wasting 40-50% license cost. Calculate: 10 hours/week saved × 50 weeks × 500 SEK = 250,000 SEK/year lost. |
| **What modules do we use most?** | Identifies utilized vs. paid-unused features. Core: Payroll, time, benefits, employee database. Advanced: Recruitment, performance, training, analytics. Using 3-4 of 10 modules = Significant underutilization. Each unused module = 10,000-30,000 SEK/year waste. License optimization opportunity. |
| **Are there modules we pay for but rarely use?** | **DIRECT cost-cutting question.** Every unused module = money wasted. Common: Recruitment (use LinkedIn), Performance (paper reviews), Learning (other LMS), Analytics (requires expertise). Typical savings from removing unused: 20-40% annual cost = 30,000-100,000 SEK/year. |
| **Do managers use the self-service features effectively?** | Manager self-service = Major selling point. If not used = ROI failure. Should handle: approvals, viewing schedules, updating info. Benefits: HR time savings, faster cycles, empowerment. If still email HR = Complete failure. Calculate lost value: 20 managers × 2 requests/month × 15 min = 120 hours/year = 60,000 SEK + 30,000 SEK unused feature = 90,000 SEK/year waste. |
| **How many hours per month do you spend in this system?** | Quantifies administrative burden. Benchmarks: 100 employees = 20-30 hours/month, 500 employees = 40-60 hours/month. If Helena spends 80 hours for 200 employees = Inefficient. 10 hours = Either highly automated (good) or underutilized (bad). Opportunity cost: Excess hours × rate = waste. 30 excess hours × 12 × 600 SEK = 216,000 SEK/year. |

## Section 4: User Experience

| Question | Rationale |
|----------|-----------|
| **How easy is it to process payroll? Any regular pain points?** | Payroll = THE core function. If painful = System failing. Easy: Automated flow, minimal manual entry, clear errors, 4-6 hours per cycle for 200 employees. Painful: Extensive manual entry, frequent errors, unclear messages, anxiety, full day+. Pain points reveal: limitations, process issues, training gaps, integration failures. Payroll errors = expensive (corrections, relations, compliance) and embarrassing. Helena dreads payroll week = RED FLAG. |
| **What do HR team members appreciate most about Agda/Visma?** | Identifies strengths to preserve. Common: Automatic tax calculations, compliance reliability, good reporting, bank integration, employee self-service. These = NON-NEGOTIABLE in replacement. Shows what users actually value vs. marketing claims. Struggles to name positives = Poor satisfaction. Strong specific answer = Value delivered. |
| **What are the top 3 frustrations with the system?** | Forces prioritization. Common: Outdated interface, slow performance, limited reporting, poor mobile, complicated workflows, inadequate support. These become: vendor negotiation points, replacement criteria, training focus. Quantify: "Slow = 10 min/day × 3 staff = 125 hours/year = 62,500 SEK." Never-fixed frustrations = Vendor neglect or fundamental issues. |
| **How intuitive is it for new HR staff? Training time needed?** | Training time = onboarding cost. Benchmarks: Simple = Days, Complex = Weeks, Enterprise = 2-3 months. 3 months productivity = Expensive: 3 months × 50% loss × 40,000 SEK = 60,000 SEK per hire. High turnover + long training = Compounding cost. Modern systems should enable basic competency within 2 weeks. |
| **How satisfied are employees with self-service features?** | Employee satisfaction affects HR workload. Can't figure out = Email/call HR instead, defeating purpose. Low satisfaction: Too complicated, poor mobile, unclear, doesn't work. Calculate: 200 employees × 2 avoidable requests/month × 5 min = 200 hours/year = 100,000 SEK. Good self-service = Strategic HR work. Poor = Transaction processor. |

## Section 5: IT Support & Maintenance

| Question | Rationale |
|----------|-----------|
| **How often do you contact IT for Agda/Visma issues?** | Frequency indicates stability and hidden costs. Daily = Major problems. Monthly = Typical. Rarely = Very stable or stopped reporting (concerning). Hidden cost: 10 IT hours/month × 800 SEK = 96,000 SEK/year beyond license. Reveals: System appropriate for users? Training gaps? IT adequacy? High burden = Unstable, poor usability, inadequate training, or too complex. |
| **How often do you contact Visma support directly? Support quality?** | Vendor support usage indicates: quality (frequent = buggy), documentation adequacy (constant help = poor docs), relationship quality. Frequent = Either responsive vendor (good) or problematic system (bad). Quality matters: "Excellent" = Positive. "Slow/unhelpful" = Frustration, consider alternatives. No use might mean: perfect (great), Helena solves internally (concerning), or gave up (very concerning). |
| **What are the most common technical problems?** | Recurring issues = Systemic problems vs. user errors. Common: Slow performance, crashes, integration failures, tax errors, report issues. One-time = Acceptable. Monthly recurring = Vendor quality problem. Pattern reveals: architecture, environment, behavior, or vendor neglect? Same issues despite "fixes" = Vendor not solving, just band-aids. |
| **How quickly are payroll-critical issues resolved?** | Time-sensitivity critical for payroll. Late payroll = Relations disaster, legal issues, penalties. Expectations: Critical = Same day, Important = 2-3 days, Routine = 1 week. 5+ days = Unacceptable. Determines vendor SLA needs. Slow resolution forces: manual workarounds, delays, overtime, complaints. One delayed payroll costs more than year of support. |

## Section 6: Integration & Efficiency

| Question | Rationale |
|----------|-----------|
| **Does Agda/Visma integrate with time tracking, banking, accounting? Manual data transfer?** | Integration determines efficiency, major value multiplier. Time = Hours flow automatic. Banking = Payments automatic. Accounting = Costs post automatic. Poor integration = Manual entry (errors), time waste, delays, reconciliation issues. Manual work: 5 hours/month × 12 × 600 SEK = 36,000 SEK/year wasted on what should be automated. Integration failure = TOP replacement reason. Manual transfer example: entering hours = 10 hours/month × 12 × 600 = 72,000 SEK/year waste. |
| **Does the system reduce manual work or create extra administrative burden?** | **Core ROI question.** Should save time, not create busywork. Reduces: Automates calculations, eliminates double-entry, streamlines approvals, self-service deflects. Creates: Complicated workflows, workarounds, data quality maintenance, error correction. "Creates more work" = Complete failure. Neutral = Wasted investment. Should see measurable savings: "Payroll 4 hours vs. 8 manual" = Clear ROI. |
| **How well does it handle Swedish payroll requirements?** | Country-specific compliance = NON-NEGOTIABLE. Must handle flawlessly: Swedish tax (A-skatt, F-skatt), social fees (arbetsgivaravgifter), pension (ITP, SAF-LO), collective agreements, Försäkringskassan, holiday pay. "Excellent, no issues" = GREEN FLAG. "Manual adjustments" = YELLOW FLAG, gaps. "Struggles with Swedish" = RED FLAG, wrong choice. Generic global systems fail local compliance. Dealbreaker - wrong here = fines, penalties, unhappy employees. Swedish-specific system essential. |

## Section 7: Future Outlook

| Question | Rationale |
|----------|-----------|
| **Is Agda/Visma keeping pace with changing labor laws and regulations?** | Regulatory changes constant. System must update automatically when laws change (tax rates, social fees, new reporting). "Always updated" = Vendor delivers. "Sometimes lag" = Concerning, compliance risk. "Often manual adjust" = Vendor failing, serious risk. Slow updates = Audit risk, penalties, manual calculations (error-prone). One tax error costs more than year of system. Vendor compliance performance = KEY selection criterion. |
| **What features are you missing that would make your work easier?** | Innovation and competitive analysis. Common missing: Better mobile, improved analytics, AI insights, better integration, modern interface. These become: vendor negotiation ("need feature X"), replacement criteria, custom development opportunities. Immediately lists 5 = She's researched, possibly frustrated. Can't think of any = Satisfied or complacent. Comparison: What do modern HR systems offer that Agda lacks? |
| **Would you recommend continuing with Agda/Visma, or exploring alternatives?** | **THE ultimate question.** Helena's daily experience = invaluable. "Definitely continue" = High satisfaction, justified. "Probably continue" = Acceptable not enthusiastic. "Unsure" = Neutral. "Consider alternatives" = Serious dissatisfaction or awareness of better options. "Definitely explore" = Strong change signal. Reasoning: Specific problems? Cost concerns? Better options? Vendor issues? Management should heavily weight this answer. Super user wants replacement = Probably should at least evaluate. |
