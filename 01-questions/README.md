## Question Categories

Each system's questions are organized into these categories:

1. **General Overview** - System purpose, history, stakeholders
2. **Technical Architecture** - Infrastructure, integrations, data flow
3. **User Experience** - Daily usage, pain points, workflows
4. **Data & Reporting** - Data quality, reporting capabilities
5. **Support & Maintenance** - Vendor support, internal expertise
6. **Future State** - Roadmap, scalability, strategic fit

## Review Checklist

Before conducting interviews, ensure:

- [ ] Questions reviewed by project lead
- [ ] Questions tailored to interviewee's role
- [ ] Estimated interview duration calculated
- [ ] Questions prioritized (must-ask vs nice-to-have)
