This folder contains raw interview data organized by system and interviewee.


## File Naming Convention

`interview-[number]-[interviewee-name]-[YYYY-MM-DD].md`

Example: `interview-001-john-smith-2025-01-15.md`

## Interview Documentation

Each interview file should include:

1. **Metadata** - Date, duration, interviewee, interviewer
2. **Context** - Interviewee's role and system experience
3. **Raw Notes** - Verbatim or near-verbatim responses
4. **Key Quotes** - Notable statements worth highlighting
5. **Follow-up Items** - Questions that need clarification
6. **Interviewer Observations** - Non-verbal cues, impressions

## Best Practices

- Document within 24 hours of interview
- Use the template from `templates/interview-notes.md`
- Mark sensitive information clearly
- Don't interpret during documentation (save for analysis phase)
