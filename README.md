Comprehensive interview analysis and insights for evaluating company systems.

```
Phase 1: Review Questions → Phase 2: Conduct Interviews → Phase 3: Collect Data
                                                                    ↓
Phase 6: Present to Management ← Phase 5: Synthesize Findings ← Phase 4: Analyze
```

## Folder Structure

```
system-interview-analysis/
├── 01-questions/           # Interview questions & rationale by system
├── 02-interviews/          # Raw interview data collection
├── 03-analysis/            # Individual system analysis
├── 04-synthesis/           # Cross-system findings & patterns
├── 05-deliverables/        # Management presentations & recommendations
├── templates/              # Reusable templates
└── docs/                   # Project documentation & guidelines
```

## Quick Start

1. **Review Questions**: Start in `01-questions/` to review and finalize interview questions
2. **Conduct Interviews**: Use templates from `templates/` during interviews
3. **Record Data**: Store raw interview notes in `02-interviews/[system-name]/`
4. **Analyze**: Document findings in `03-analysis/[system-name]/`
5. **Synthesize**: Compile cross-system insights in `04-synthesis/`
6. **Deliver**: Prepare final recommendations in `05-deliverables/`

## Status Tracking

Update the status in each system's tracking file as you progress:

- `NOT_STARTED` - Work has not begun
- `IN_PROGRESS` - Currently working on this phase
- `IN_REVIEW` - Completed, awaiting review
- `COMPLETED` - Finished and approved

## Version Control Guidelines

- Create feature branches for major updates
- Use meaningful commit messages: `[system] phase: description`
- Examples:
  - `[idus] questions: add technical integration questions`
  - `[all] synthesis: complete cross-system comparison`
