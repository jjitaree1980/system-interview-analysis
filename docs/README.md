# Project Documentation

This folder contains project management documentation and guidelines.

## Contents

```
docs/
├── project-charter.md        # Project scope, objectives, stakeholders
├── methodology.md            # Research methodology and approach
├── interview-guide.md        # How to conduct interviews
├── coding-guide.md           # How to code/analyze interview data
├── meeting-notes/            # Project meeting documentation
│   └── YYYY-MM-DD-meeting.md
├── status-reports/           # Regular status updates
│   └── YYYY-MM-DD-status.md
└── decisions/                # Key decisions and rationale
    └── YYYY-MM-DD-decision.md
```

## Key Documents

### Project Charter
Defines scope, objectives, stakeholders, and success criteria.

### Methodology
Documents the research approach:
- Interview design
- Sampling strategy
- Analysis methods
- Quality controls

### Interview Guide
Practical guidance for interviewers:
- Preparation checklist
- Conducting the interview
- Handling difficult situations
- Post-interview procedures

### Coding Guide
Instructions for analyzing qualitative data:
- Code definitions
- Coding process
- Inter-rater reliability
- Theme development

## Meeting Notes

Document all project meetings with:
- Date and attendees
- Agenda items
- Discussion summary
- Action items with owners
- Next meeting date

## Status Reports

Regular updates should include:
- Accomplishments since last report
- Current activities
- Upcoming work
- Risks and issues
- Decisions needed
