# Templates

Reusable templates for consistent documentation throughout the project.

## Available Templates

| Template | Purpose | Used In |
|----------|---------|---------|
| `interview-notes.md` | Document interview sessions | 02-interviews/ |
| `interview-questions.md` | Structure interview questions | 01-questions/ |
| `system-analysis.md` | Analyze individual systems | 03-analysis/ |
| `comparison-matrix.md` | Compare systems side-by-side | 04-synthesis/ |
| `meeting-notes.md` | Document project meetings | docs/ |
| `status-report.md` | Weekly/monthly status updates | docs/ |

## Usage

1. Copy the template to the appropriate folder
2. Rename following naming conventions
3. Fill in all sections
4. Remove any unused optional sections
5. Update status tracking

## Customization

Templates can be customized for project needs:
- Add project-specific sections
- Remove irrelevant sections
- Adjust formatting
- Update default values

Keep a changelog if modifying templates significantly.
