# Opportunities - Agda PS

## Overview

**System:** Agda PS (Payroll System)
**Analysis Date:** December 2025
**Source:** Interview with Helena (Super User)

This document identifies potential opportunities for improvement, optimization, and value enhancement based on current system usage and stakeholder needs.

---

## 1. Banking System Integration

**Category:** Process Automation
**Priority:** High
**Estimated Impact:** High - Reduces manual work and error risk in time-sensitive process
**Implementation Complexity:** Medium

### Current State
Manual data generation and transfer to Ekonomi team for bank uploads each payroll cycle.

### Opportunity Description
Implement direct integration between Agda PS and banking system to automate payroll data transfer. This would eliminate manual export/import steps and reduce coordination dependency between HR and Ekonomi teams.

### Potential Benefits
- Eliminate manual data generation for banking
- Reduce risk of data transfer errors
- Save time in each payroll cycle
- Reduce coordination overhead between teams
- Faster payroll-to-bank processing

### Implementation Path
- Consult with Visma on banking integration capabilities
- Engage Ekonomi team to understand banking system requirements
- Assess integration options and costs
- Pilot integration with one payroll cycle
- Roll out full automation

### Success Metrics
- Zero manual banking data transfers
- Reduced payroll processing time
- Elimination of data transfer errors
- Positive feedback from Ekonomi team

## 3. Self-Service Adoption Enhancement

**Category:** User Experience / Change Management
**Priority:** Medium
**Estimated Impact:** Medium - Reduces HR administrative burden
**Implementation Complexity:** Low

### Current State
Some employees still submit leave requests on paper instead of using self-service features. Incomplete time data occasionally requires manual follow-up.

### Opportunity Description
Increase employee adoption of self-service features through targeted training, improved change management, and user engagement. This would reduce manual data entry for HR and improve data completeness.

### Potential Benefits
- Eliminate paper leave request processing
- Reduce manual data entry by HR team
- Improve time data completeness
- Better employee engagement with system
- Cost savings from full utilization of purchased features

### Estimated Cost Savings
If self-service features are underutilized, the company may be losing value on purchased but unused functionality. Full adoption could save HR team 2-4 hours per week in manual processing.

### Implementation Path
- Conduct employee survey on self-service barriers
- Develop targeted training for low-adoption users
- Create simple user guides and quick reference materials
- Provide computer literacy support for struggling users
- Communicate benefits of self-service to employees
- Consider incentives for digital adoption

### Success Metrics
- 90%+ of leave requests submitted via self-service
- Reduced incomplete time data entries
- Decreased HR manual data entry time
- Improved employee satisfaction scores

## 5. Shift Calculation Automation

**Category:** Process Optimization
**Priority:** High (Short-term)
**Estimated Impact:** Medium - Addresses current pain point
**Implementation Complexity:** Low

### Current State
New shift working times (October 2025) require manual review to verify calculation accuracy. This is the only regular pain point in current payroll processing.

### Opportunity Description
Work with Visma to configure and validate shift time calculations, eliminating the need for manual review. This would restore the "very easy" payroll process Helena previously experienced.

### Potential Benefits
- Eliminate manual review time in each payroll cycle
- Reduce risk of calculation errors
- Restore full confidence in automated calculations
- Save Helena's time for higher-value work

### Implementation Path
- Document specific shift calculation requirements
- Work with Visma support to configure rules
- Test calculations with sample data
- Validate over 2-3 payroll cycles
- Remove manual review once validated

### Success Metrics
- Zero manual reviews required
- 100% accurate shift calculations
- Return to "no pain points" status for payroll processing

## 7. Two-Person Coverage Establishment

**Category:** Risk Mitigation / Business Continuity
**Priority:** High
**Estimated Impact:** High - Reduces business risk
**Implementation Complexity:** Low (Already in progress)

### Current State
Helena is primary system expert with 7 years experience. New HR team member with Agda PS experience has been recruited.

### Opportunity Description
Fully establish two-person coverage for payroll processing by training new team member and documenting critical workflows. This reduces single-point-of-failure risk and provides backup coverage.

### Potential Benefits
- Business continuity during absences
- Reduced dependency on single person
- Knowledge sharing and validation
- Increased capacity for system improvements
- Succession planning

### Implementation Path
- Complete onboarding of new HR team member
- Document critical payroll workflows
- Cross-train on all payroll processes
- Establish coverage rotation
- Create escalation procedures

### Success Metrics
- Both team members can process full payroll independently
- Documented workflows for all critical processes
- Successful payroll processing during Helena's absence
- Reduced business continuity risk
