# Flexite System Assessment - Key Themes

**System:** Flexite (Incident Management)  
**Assessment Date:** 2026-01-08  
**Super User:** Jan-Eric  
**System Criticality:** 9/10

---

## Theme 1: Strong Core Functionality with Excellent User Adoption

**Summary:**
Flexite successfully serves as Kubal's incident management platform with 100% reporting compliance and high user satisfaction. The system handles 120-140 monthly incidents effectively and meets all Swedish legal requirements.

**Evidence:**
- 100% incident reporting rate through system
- 1,572 reports processed in 2025
- Employees have to using Flexite even calling/emailing
- Easy to use interface for all employee levels
- Excellent system performance and reliability
- Minimal IT support required
- Daily usage by safety administrator
- Mobile and web access available

**Impact:**
System effectively supports safety compliance and enables preventive action development that reduces incidents over time.

---

## Theme 2: Critical Integration Gaps Create Manual Work

**Summary:**
Flexite operates as an isolated system with no integration to government reporting, facilities management, HR, or insurance systems. This forces time-consuming manual data entry and increases error risk.

**Evidence:**
- No e-tjänster (government) integration - requires manual login and data entry for 12 monthly reports
- No Idus integration for maintenance-related incidents
- No Agda/Visma integration for personnel data
- No insurance system connection for accident claims
- Only email notifications exist - no system-to-system data exchange

**Impact:**
Manual processes create administrative burden, increase error risk, and prevent seamless workflow across safety, maintenance, and HR functions.

**Cost Implication:**
Manual government reporting and data re-entry represents significant recurring waste. Exact hours to be calculated.

---

## Theme 3: Manual Reporting Process Limits Analytics Value

**Summary:**
While Flexite captures incident data effectively, creating management dashboards and analysis reports requires 30-45 minutes of manual data extraction and Excel manipulation per reporting cycle.

**Evidence:**
- Management dashboards created manually by exporting and pasting data
- LTA (Lost Time Accident) reports formulated manually in Excel
- No automated analysis reports in system
- No built-in dashboards matching management requirements
- 30-45 minute time investment per reporting cycle

**Impact:**
Manual reporting process delays insights, increases administrative burden, and limits real-time visibility into safety trends.

**Cost Implication:**
30-45 minutes per reporting cycle × frequency × hourly rate = quantifiable annual waste

---

## Theme 4: Compliance Strength but Workflow Inefficiency

**Summary:**
Flexite fully meets Swedish safety compliance requirements and provides excellent audit trails, but manual processes reduce efficiency and prevent optimization of safety workflows.

**Evidence:**
- Fully meets Arbetsmiljöverket requirements
- Adequate audit trails maintained
- Easy compliance demonstration to auditors
- However: manual government reporting contradicts digital compliance approach
- Cross-team coordination for preventive actions is complex but necessary

**Impact:**
System ensures compliance but doesn't leverage automation to make compliance processes more efficient.

---

## Theme 5: Investment Opportunity in Automation

**Summary:**
Jan-Eric recommends investing in Flexite enhancements, specifically automated reporting and system integrations that would reduce manual work while maintaining the strong core functionality.

**Evidence:**
- Super user recommendation: "Invest more"
- Specific request: analysis reports matching management needs
- Willingness to adopt enhanced features if useful
- Recognition that automated dashboards would add value

**Impact:**
Investment in reporting automation and integrations would preserve strong user adoption while eliminating manual waste and improving analytics capabilities.

---

## Strategic Implications

**System Strengths to Preserve:**
- High user adoption and 100% compliance rate
- Easy-to-use interface
- Excellent performance and reliability
- Strong audit trail capabilities

**Investment Priorities:**
1. Government system integration (e-tjänster) - eliminate manual double-entry
2. Automated dashboard and analysis reporting - reduce 30-45 minute manual cycles
3. System integrations (Idus, Agda/Visma, insurance) - enable seamless workflows

**Risk of No Action:**
Continued manual processes waste administrative time, increase error risk, and limit real-time safety insights that could further reduce incidents.
