## 🔍 PORTFOLIO-LEVEL STRATEGIC FINDINGS

### Finding 1: Analytical Capability Gap Across Portfolio

**Discovery:** Only 1 of 4 systems operates at modern analytical maturity

| System | Intelligence Level | Status |
|--------|-------------------|--------|
| Ascendo | ⭐⭐⭐ Best-in-class | Predictive matching, automated routing |
| Agda/Visma | ⭐⭐ Proactive available | Features exist but underutilized |
| Idus | ⭐ Should be proactive | Broken integration prevents it |
| Flexite | ⚠️ Reactive only | No analytical features by design |

**Business Impact:**
- Manufacturing operations rely on manual analysis and human judgment
- Systems function as data repositories, not decision-support tools
- Limits ability to move from reactive to predictive operations
- Ascendo proves analytical excellence IS achievable at Kubal

**Recommendation:** Use Ascendo as internal benchmark. Consider analytical maturity in future IT strategy—not every system needs advanced analytics, but 1 of 4 is below industry standard.


**Comparison - What "Good" Looks Like:**
- **Ascendo → SAP:** Perfect integration, zero manual entry, 900-1,800 hrs saved/year
- **Idus → SAP:** Broken integration, 100% manual entry, massive waste

**Recommendation:** Fix the SAP integration OR replace Idus with modern CMMS that integrates properly. This single fix could eliminate 56% of portfolio waste.

### Finding 4: User Capability vs System Barriers

**Critical Discovery:** Same users show completely different adoption patterns

| User Group | Idus Adoption | Flexite Adoption | Conclusion |
|------------|---------------|------------------|------------|
| Shift Leaders | ❌ Excel workarounds<br>❌ Can't access directly<br>❌ Approval bottleneck | ✅ Direct entry<br>✅ 100% compliance<br>✅ No workarounds | Problem is SYSTEM<br>not USER capability |

**This Proves:**
- Shift leaders ARE capable of using systems directly (Flexite evidence)
- Idus barriers are system design/permission issues, not training gaps
- Excel workarounds = symptom of system-user misalignment

**Recommendation:** Before investing 800K in Idus upgrades, diagnose root cause:
- Is Idus too complex? → Need different system
- Are permissions too restrictive? → Need access + training
- Is approval required by policy? → Validate if policy appropriate
